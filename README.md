One line: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

> "I put the deadline in my long-term memory. I have no long-term memory."

`main.ts` (Node 22, stdlib only) writes exactly that line to `/output/entry.txt`.
See [METHOD.md](METHOD.md) for the 30-candidate tournament that picked it.
